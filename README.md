# ✉️ AiEmail Generator

A lightweight, high-performance web application built with Flask and the Groq API (openai/gpt-oss-20b) that generates tailored, professional email subject lines and body content in seconds.

Featuring a vibrant, soft pastel UI, real-time generation states, and one-click copy functionality.
